01 / 検証の内容

LayaをLambdaのコンテナ内で動かし、IAM認証付きのAPI Gatewayから呼び出しました。目的は動作・速度・判定の正しさを確かめることです。初期化の高速化やモデルのチューニングは行っていません。

何を正解としたか

肯定34件・中立33件・否定33件の期待値と理由を、推論前に固定しました。全体として評価・満足が優勢なら肯定、不満・失望が優勢なら否定、事実だけの説明や賛否同程度なら中立としています。

作成担当とは別のAIが100件を確認しました。人による独立したアノテーションではありません。モデルには本文と共通質問だけを渡し、期待値や採点理由は渡していません。

モデルに送った共通質問を確認する

    "criteria": {
      "positive": "肯定的。満足、評価、好意が全体として優勢。",
      "neutral": "中立。事実の記述が中心、または良い点と悪い点が同程度で評価が定まらない。",

    }
  }
}

固定シードで実行順を並べ替え、自動再試行は行っていません。APIのchoiceを採用し、返された確率の最大候補と一致することを検査しました。結果を見てから期待値や質問を変更することはしていません。
